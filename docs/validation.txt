ThumbType v0.7 / 2026-11-03

変更
- アプリ名をThumbType、実行ファイル名をThumbType.exeへ変更。
- 提供されたNICOLA.yabを内蔵し、48キー×4層に拡張。
- 添付形式の.yab直接読み込みと5列TSV、小指シフトに対応。
- 無・後・逃を無出力・Backspace・Escapeとして処理。
- Unicodeによる直接出力方式を維持。元IMEへのローマ字入力とは異なる。

確認済み
- ビルド成功。実行ファイルの製品名・バージョンも更新。
- 入力処理250項目合格（self-test.txt）。
- このうち192項目で、添付の48キー×4層を独立した期待値と照合。
- ん、っ、小指Shift、無出力、Backspace、Escape、未対応YABの拒否を確認。
- 提供されたUTF-16LE .yabと変換済み5列TSVの直接読み込みを確認。
- 設定復元10項目、起動予約6項目、トレー動作11項目合格。
- 全4タブを描画して画面確認。

実機での確認が必要
- JISキーボードの各OEM記号キーが意図した位置に対応するか。
- 日本語IMEと対象アプリ上での物理キー入力、変換・候補選択。
- 左Shift小指シフトと右Shift親指シフトの実操作。
- 実フックの緊急停止、強制終了、スリープ・ロックからの復帰。

自動検証は実キーボードフックや実入力送信を行っていない。
全やまぶきR形式・IME動作との互換性や完全な異常復旧は保証していない。

メモ帳での確認例（IMEを「あ」にする）
; = ん / 右Shift+; = っ / Space+Z = ぅ / 右Shift+/ = ぉ
左Shift+1 = ！ / J = と / 右Shift+J = お
IMEを「A」にしたらJ = jになることも確認する。
旧サンプルを記憶している場合、停止して「内蔵NICOLA」を選んで開始する。

v0.7の変更と検証

- 起動時・設定表示時は登録状態の照会のみ。チェック操作時だけ変更。
- ユーザーのStartupフォルダの管理対象ThumbType.lnkだけを作成・解除。
- スタートアップ登録12項目に合格（registration-test.txt）。

- 入力250項目、配列設定10項目、起動予約6項目、トレー11項目も合格。
- 5タブを描画して確認。
- Windowsへの再ログインによる実起動と、Windows側の無効化ポリシー等は未検証。
